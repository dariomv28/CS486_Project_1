# SKILL DEFINITION: DATABASE DESIGN AND SQL IMPLEMENTATION

This file defines the specific skills and capabilities you must use to complete the Phase 1 tasks.

## 1. Required Skills

### 1.1. Business Requirement Analysis
* Ability to analyze text to extract actors, entities, attributes, relationships, cardinalities, and business rules.

### 1.2. Conceptual Database Design (ERD)
* Ability to draw an Entity-Relationship Diagram (ERD) that correctly illustrates entities, their attributes, relationships, cardinalities, and participation constraints.

### 1.3. Logical Database Design
* Ability to convert an ERD into a relational schema.
* Ability to correctly define relations, attributes, primary keys, foreign keys, candidate keys, and key constraints.

### 1.4. Database Design Validation
* Ability to evaluate and verify that the relational schema matches the ERD and fully satisfies all stated business rules.

### 1.5. Database Implementation (SQL DDL)
* Ability to write SQL DDL scripts to create tables.
* Ability to apply primary keys, foreign keys, unique constraints, NOT NULL constraints, CHECK constraints, and DEFAULT values.

### 1.6. Sample Data Preparation
* Ability to write SQL INSERT statements with realistic testing data.
* Data must cover normal database operations and exceptional validation cases (such as testing overlapping bookings or booking a room under maintenance).

### 1.7. Query Design
* Ability to write SQL queries to answer business questions.
* Ability to use standard relational operations (filtering, joining, grouping, and aggregating) to provide useful information for target users like staff or managers.
